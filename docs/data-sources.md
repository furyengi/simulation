## Handling

- All external values keep `provider`, observation/model epoch, retrieval time, native units and
  freshness (see [provenance](provenance.md)).
- Caches live under `SIM_CACHE_DIR` (git-ignored); small dated fixtures used by tests are committed
  with their source URL and retrieval date.
- With `SIM_OFFLINE=1` no network requests are made; the engine uses cache/fixtures and reports
  the resulting data age honestly.
- No credentials are ever committed; OpenSky credentials, when used, come from the environment.
