# Reference data: Orekit

- `orekit-reference.csv` — generated by `validation/orekit/src/main/java/sim/OrekitReference.java`
  with **Orekit 13.1.8** (Apache-2.0, https://www.orekit.org), Java 21 (Temurin), by the GitHub Actions
  workflow `.github/workflows/orekit-reference.yml` (run 36751600928, 2026-09-30).
- Orekit data: `orekit-data` (main branch, https://gitlab.orekit.org/orekit/orekit-data) downloaded by
  the workflow; EOP from `finals2000A.all` (IERS Bulletin A/B, file dated 2026-09-03; see
  `orekit-eop-files.txt`). The Earth Orientation Parameters Orekit actually used at each instant are
  written into the CSV (`eop` rows) so the comparison can feed exactly these values to Simulation.
- Inputs: `../inputs/tles.txt` — three TLEs fetched from CelesTrak on 2026-09-30 (ISS, GOES 14,
  GPS BIIR-5), offsets 0, 1, 6, 12, 24, 48 h from the element epoch.
- Orekit configuration: `TLEPropagator`; frames TEME, ITRF (IERS 2010 conventions, simple EOP:
  no sub-daily tidal terms) and GCRF; WGS 84 from `Constants.WGS84_EARTH_EQUATORIAL_RADIUS` and
  `WGS84_EARTH_FLATTENING`.
- To regenerate: run the workflow, download the artifact, replace these files.
