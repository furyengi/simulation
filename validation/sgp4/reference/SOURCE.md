# Reference data: Vallado SGP4 verification suite

- `SGP4-VER.TLE` — 33 verification element sets (input).
- `tmatverDec2015.out` — reference TEME position (km) and velocity (km/s) at listed minutes since epoch,
  generated by Vallado's MATLAB implementation (December 2015 revision), WGS-72 constants.
- Origin: David Vallado's SGP4 software as mirrored at https://github.com/poliastro/vallado-software
  (`matlab/`), commit `50ca0e5e3375b39d3cb6c91b8c46109c796fd8ae`, retrieved 2026-09-30. The suite accompanies
  Vallado, Crawford, Hujsak, Kelso, "Revisiting Spacetrack Report #3", AIAA 2006-6753
  (https://celestrak.org/publications/AIAA/2006-6753/).
- Files are committed verbatim.
